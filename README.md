# 🐢 Turtle Crossing Game

A simple **Turtle Crossing Game** built with Python and Turtle graphics.

## 🎮 About the Game

The goal is to help the turtle cross the road while avoiding moving cars. The game becomes more challenging as the player progresses.

## 🛠️ Technologies Used

* Python
* Turtle Graphics

## 🧠 Concepts Practiced

* Object-Oriented Programming
* Player Movement
* Keyboard Controls
* Collision Detection
* Game Loop
